
# Random Quote Generator

A full-stack Random Quote Generator built using HTML, CSS, JavaScript, Node.js and Express.

## Live Website

https://final-nodejs-project-ziqo.onrender.com/

## GitHub Repository

https://github.com/tarun9059/final-nodejs-project

## Features
- Generate random motivational quotes
- Display quote author
- Copy quotes to clipboard
- Responsive user interface
- Node.js backend API

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
